# cave atlas icon

The canonical source is `icon.png`, a transparent PNG. Web derivatives are 96px (`web/icon.png`), 32px (`web/favicon.png`) and 180px (`web/apple-touch-icon.png`). Use Lanczos downsampling and preserve alpha. The source is not shipped with the dashboard; the smaller derivatives are.

Created with the built-in image generation tool using modo and fairway as style references. The generator baked in a checkerboard; with the owner's explicit permission, the outside background was removed programmatically using the enclosed charcoal outline as the silhouette. Interior artwork was preserved. The icon is original project artwork under MIT.

## Original prompt

```text
Create one original project icon for cave atlas. The two referenced images are STYLE REFERENCES only (modo blue map, fairway green map); do not modify them. Match their tactile matte illustrated folded-paper map family: broad simple folded panels, bold rounded charcoal outline, subtle shading/grain, compact friendly shape, genuine transparent background. Subject: a softly folded warm sand/ochre paper map with one small pale limestone cave entrance rising naturally from the central panel: chunky rounded rock arch surrounding a deep charcoal opening, one tiny broad stalactite silhouette so it reads as a natural cave, not a tunnel. One short charcoal curving exploration line on a map panel may approach the cave. Make map and cave one coherent icon, very sparse at favicon size. Colors warm parchment map, muted ochre folds, ivory stone and charcoal. Entire object centered with clear transparent margins, fills about 78% square; no cast shadow outside object. Square transparent PNG. No text, letters, numbers, pins, flags, people, faces, extra objects, badges, tiles, scenery, background color, or checkerboard.
```

## Background edit prompt

```text
Preserve the cave-and-map icon exactly. Remove the entire gray checkerboard and all background texture outside the object. Deliver a transparent PNG with a real alpha channel, alpha=0 outside the outlined map object. The checkerboard must NOT be painted into RGB pixels. No background, no outside shadow. Keep the icon's matte ochre folded map, ivory cave arch, charcoal route, contours, framing and colors unchanged.
```
