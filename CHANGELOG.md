# Changes

## 0.2.0 — 2026-09-09

First cave atlas dashboard release, continuing the cavebot repository under snowball-projects.

- Publish the accepted map-first interface: compact cave list and filters, unlimited selection within the catalogue, aligned depth/length comparison bars and source/search links.
- Add the cave atlas icon and lowercase identity; adapt panels for narrow screens and keep source information behind the information button.
- Ship a reviewed 45-record catalogue with exact source revision, date, license and regional coordinates. Bundle Leaflet locally.
- Replace the old Folium command and packaging with a reproducible static build, offline checks and GitHub Pages deployment. Preserve the source parser, applicable tests and v0.1.x history.
- Document operation, costs, privacy, revival, catalogue expansion and an optional future CaveView survey pilot. No 3D feature or additional catalogue is included in this release.
